# 자람 (Jaram)

부모를 위한 월령별 육아용품 큐레이션 프로토타입입니다.

## 실행

Node.js 24 / npm 11에서 검증했습니다.

```sh
npm ci
npm run dev -- --port 5173
```

프로덕션 빌드: `npm run build`

## 구현

- 월령, 카테고리, 선택 기준, 검색어 필터
- 최대 3개 제품 비교표
- localStorage 기반 제품 저장과 월령 기억
- 제품 상세 및 매거진 읽기
- 반응형 한국어 UI 및 자체 SVG 제품 일러스트

제품·가격·추천은 예시입니다. 실제 리뷰, 인증 검증, 최저가, 회원, 커뮤니티, 제휴 구매는 미연동입니다. 저장 데이터는 현재 브라우저에만 보관됩니다.

## 검증

프로덕션 빌드, 개발 서버 HTTP 응답 및 jsdom에서 검색/필터/저장/비교/상세 동작을 검증했습니다. 실제 브라우저의 시각적 검증은 수행하지 않았습니다.
